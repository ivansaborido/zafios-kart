# Zafios Kart · APK

1. Sube todo esto a un repositorio de GitHub (incluida la carpeta `.github`).
2. Pestaña **Actions** → **Compilar APK** → **Run workflow**.
3. A los ~10 minutos, el APK aparece en **Releases** (columna derecha de la página del repositorio) → `Zafios-Kart.apk`.

Cada vez que subas un `Zafios_Kart.html` nuevo, el APK se vuelve a compilar solo.
