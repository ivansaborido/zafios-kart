ZAFIOS KART · Sacar el APK con GitHub

4 pasos. No hay que instalar nada en el ordenador: GitHub compila el APK por ti.

1
Crea el repositorio. En github.com: + → New repository, nombre zafios-kart, Public → Create repository.

Create repository
2
Sube los archivos. Descomprime el ZIP. En el repositorio pulsa uploading an existing file y arrastra todo lo que hay dentro de la carpeta: Zafios_Kart.html, la carpeta app, la carpeta .github y el README.md. Abajo, Commit changes.
Add files via upload
Drag files here to add them to your repository

Commit changes
La carpeta .github es la importante (es la que compila). Está oculta: en Windows, Explorador → Vista → Elementos ocultos; en Mac, Cmd + Mayús + . en el Finder.
Si no te deja subirla: Add file → Create new file, en el nombre escribe .github/workflows/compilar-apk.yml, pega dentro el contenido de ese archivo (ábrelo con el Bloc de notas) y Commit changes.
3
Compila. Pestaña Actions → a la izquierda Compilar APK → Run workflow → Run workflow (botón verde).
CodeActionsSettings
Compilar APK
This workflow has a workflow_dispatch event trigger. Run workflow ▾
Si al entrar en Actions te sale un botón «I understand my workflows, go ahead and enable them», púlsalo primero. Tarda unos 10 minutos; espera al círculo verde ✅.
4
Descarga el APK. En la página principal del repositorio, columna derecha, Releases → Zafios-Kart.apk. Ese enlace lo puedes abrir directamente desde el móvil o mandarlo por WhatsApp.

En el móvil, al abrirlo, Android pedirá permiso para instalar apps desconocidas: acéptalo. Si ya tenías una versión, se actualiza encima.
Para actualizar el juego: sube un Zafios_Kart.html nuevo al repositorio (mismo nombre). El APK se compila solo y sale una versión nueva en Releases.
Si sale en rojo ❌: entra en la ejecución, pulsa el paso que falló y copia las últimas líneas. Pásamelas y lo arreglo.
